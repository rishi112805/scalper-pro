# 🤖 Scalper Pro — Automated Options Trading Bot

A fully automated algorithmic options trading bot connected to Angel One broker via SmartAPI.

## Features
- Real-time WebSocket price feed
- RSI + EMA + Volume signal scoring
- Automated risk management (SL, Target, Daily limits)
- Paper trading mode for strategy validation
- Live Flask web dashboard
- NIFTY, BANKNIFTY, SENSEX options trading

## Tech Stack
Python | Flask | Angel One SmartAPI | WebSocket | Pandas | Chart.js

## Setup
1. Clone the repo
2. Install dependencies: `pip install -r requirements.txt`
3. Add your Angel One credentials
4. Run: `python3 demo_scalper.py`

## Dashboard
Run: `python3 dashboard.py`
Open: `http://127.0.0.1:8080`
